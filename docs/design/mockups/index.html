What changed in v4

  • Links look like links: mauve and underlined. → stays in the app, ↗ opens the thread. Post titles are links.
  • Actions are buttons: a bright edge and a hard shadow, and they press in when clicked. Plain text is never mauve or underlined.
  • Choices fill: every option, model and time fills with mauve when picked. No browser dropdowns: the time is a themed grid (◷ in the top bar, and Settings).
  • Less text: no eyebrows above titles; one short line under each title; the Reddit cost is a small equation (7 phrases × 1 a day = 217 this month) with a plan meter.
  • Build notes are separate: every explanation meant for the build agent is a dashed yellow agent-note block, hidden by default. Turn them on with "build notes on/off" (bottom right).
  • Keyboard toolbar removed: shortcuts now live only in review mode, printed inside the buttons they trigger (Skip S, Done D, Copy C), with a "Keyboard shortcuts" link. Mouse users never need them.
  • Logo: the quote mark in a square, redrawn with the same block and hard-shadow edges.
